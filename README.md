# bioONE

This project is made by Dhruv Dagar (me) for students who struggle with textbooks like I did. I often found it hard to imagine how biological processes actually work—for example, I always wondered how mitochondria made ATP and how it was transported, but it was difficult for me to visualize.

I have been interested in biology since childhood and always wondered about questions that seemed to make no sense to teachers, like: *"If every cell has the same DNA, how does it know when to do what and what not to do—for example, when to process food, when to release dopamine, and when not to?"*

## Future of bioONE

The future of bioONE is certain because this is a passion project made for people, not for views or visitors. This project will only continue to expand. I am thinking of adding an AI that takes questions and answers them (using your own notes too), along with more interactive topics—but that is for later.
